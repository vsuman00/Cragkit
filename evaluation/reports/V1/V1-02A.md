## Outcome and ownership

This child implements the internal resource layer for optional native Python PostgreSQL connections. Owned pools open explicitly and close with Cragkit; borrowed pools remain caller-owned. Startup, acquisition, queued requests and closure have explicit limits. Core import does not load a driver, connect or apply migrations.

Sol peer A authored `packages/python/src/cragkit/_postgres_pool.py` and assembled the result. Sol peer B authored `packages/python/tests/test_postgres_pool.py`. They agreed A-r1 directly before dependent edits and resolved closure cases together. Both stopped writes and explicitly transferred ownership to root. Root completed the final deadline postcondition and regression cases, documentation, all execution and integration. Public contracts, core exports, manifests/locks, migrations, TypeScript and sealed evaluation inputs are unchanged.

## Limits and next action

This internal foundation is not a complete store adapter. Its lease deadline bounds acquisition; callers still own body deadlines and explicit transactions. One resource belongs to one event loop. Cleanup bounds assume cooperative async driver methods; cancellation-resistant work produces an explicit failure rather than a successful shutdown claim. Borrowed pools are not reconfigured or security-validated by this child. Wrapper admission is capped by `max_size + max_waiting`; it does not control unrelated caller work on a borrowed pool.

Schema compatibility, tenant isolation, query filtering, statement budgets, ingestion and retrieval remain later acceptance criteria. The hosted administrative check does not establish runtime authorization. No permanent role, policy, migration, model or local server was introduced.

Learning remains pending. Failure example: closing a caller's borrowed pool would break unrelated application requests. Next: V1-02B binds trusted scope, checks schema/capabilities and verifies a real runtime role. Exercise: explain why the borrowed driver remains open after `PoolResource.close()` while that wrapper rejects new leases.
