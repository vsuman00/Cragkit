# V6-C2: candidate artifacts and CI acceptance

V6-06 and V6-C2 are complete for the declared candidate matrix. The single
approved private [CI run](https://github.com/vsuman00/Cragkit/actions/runs/41625938303)
passed against source `0c7c568d5cb71638eebab2dea97c5973b0f8cc08`.
The [CI report](V6-06-ci.md), [licensing preparation](V6-06-licensing.md),
[compatibility report](V6-06-compatibility.md) and
[acceptance record](V6-06-verification.json) distinguish each evidence type.

For example, the same package version can contain different bytes. Adding an
installed Python file or changing one Node dist byte failed the identity gate.
Restoring the original bytes restored the exact target identity. Versions name
a release; hashes bind the tested products.

All twelve retained products passed hash, member, dependency/content, MIT and
NOTICE checks; direct and sdist-rebuilt wheels had identical members. Hosted
core, LangChain and MCP suites and exact installation profiles passed. Three
initial build-order skips passed locally after builds. The future workflow now
runs them after all SDK builds; that amendment has not run in hosted CI.
The final local Python/tool suite passed 3,968 tests, no skips and four existing
intentional Pydantic warnings. The two new checkers passed 32 focused tests.

The exact CI core products passed fresh default import, RSS and logical-size
limits on the M4/16 GiB laptop. Both native runtimes also passed twelve resource
checks, including backpressure, cancellation, bounded reuse, scope, source spans
and strict tokens. Each consumed all 39 sealed provider recordings and produced
30 rows/five receipts matching the original output after timing normalization.
There were no new model HTTP calls. This proves recorded-output compatibility;
the original live benchmark and its known small-sample limitations remain intact.

Default measurement pressure was 39-41 percent free memory, native measurement
pressure 36 percent, with no swapout growth within either bounded run. Later
system paging remains a reason to monitor headroom before new native work.
All owned database processes/listeners were closed. Selected credential scanning
and final scoped Git review are recorded in the tracker handoff.

The repository remains private and packages unpublished. Migration/rollback,
publication and maintenance gates remain required. No production or independent
human-usability claim follows from this checkpoint. Learning practice remains
unassessed: explain why matching version strings would not catch the two rejected
installed-file changes. Next is V6-07 on disposable data.
