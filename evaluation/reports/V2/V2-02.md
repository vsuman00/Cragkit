# V2-02: Bounded native Python embeddings

Date: 22 October 2026. State: COMPLETE for the Python adapter boundary under [E-r1](../../../contracts/EMBEDDINGS_V2.md). This is deterministic local implementation/verification, with no live API, model-quality, billing, database, hosted CI or installed-artifact evidence.

## Behavior and design

Example: a request contains two texts and the provider returns indexes 1 then 0. The adapter validates both vectors and returns them in input order. A duplicate index fails even if every vector has the correct length. This avoids attaching an embedding to the wrong source.

Added `packages/python/src/cragkit/embeddings.py` and focused tests. The adapter accepts an application-owned cooperative async transport and accurate named token counter; no new dependency, credential discovery, concrete HTTP client, tokenizer asset or background service was introduced. Neither the core package nor PostgreSQL implementation changed. Injected transports are responsible for actual HTTPS/TLS, endpoint/redirect rules, streaming bounds, timeouts and retry suppression; these were not tested against a live endpoint. This boundary cannot sandbox caller code or interrupt blocking/noncooperative callbacks.

The accepted real profile is OpenAI text-embedding-3-small, explicit 1536 dimensions, `cl100k_base`, L2 normalization and application revision `openai_te3small_1536_r1`. Default operation uses the separate fake profile and fake model identity. Real-profile selection alone leaves live dispatch disabled. Live opt-in also requires explicit policy, positive configured price and sufficient estimated per-operation allowance. No profile or counter can be chosen through agent-editable retrieval input in this API; the application binds them at construction.

Queries delegate to batches. Inputs are snapshotted before dispatch; item, per-input/aggregate UTF-8 bytes and named-token counts are bounded before the one permitted transport call. Expired deadlines fail, concurrent work is rejected without a waiting queue, cancellation propagates to cooperative transport and the same adapter can be reused after cleanup. There is no splitting, truncation, retry or silent lexical downgrade.

Raw responses are bounded bytes and strict JSON: invalid UTF-8, duplicate keys and nonstandard numeric constants fail. Every returned index must occur once, match a requested input and resolve to a 1536-component numeric finite unit vector within tolerance 0.001. Model/dimension mismatch uses the existing profile-mismatch error; malformed provider output and transport faults use sanitized provider errors. Output metadata and vectors are immutable copies.

Missing live token usage/cost stays unknown. Known live usage produces estimated cost from the configured price; fake cost is known zero with synthetic provenance. Cost arithmetic uses a fresh Decimal context so unrelated application arithmetic settings cannot weaken the preflight comparison. The preflight gate is not a verified provider-billing ceiling or cross-process quota. Failed/cancelled dispatched operations may incur charges; exceptions establish no zero-usage claim. The shared request ledger remains V4 work.

## Verification

Run sequentially from the project root:

```sh
uv run --project packages/python --frozen pytest packages/python/tests/test_embeddings.py -q
uv run --project packages/python --frozen mypy --config-file packages/python/pyproject.toml packages/python/src
uv run --project packages/python --frozen pytest packages/python/tests tools/tests -q
```

Final results: **109 focused tests passed in 0.14 seconds**, **strict mypy passed across 16 source files**, and **544 Python/tool regression tests passed in 1.60 seconds**, with no final warnings. Runtime: Python 3.14.6 and Pydantic 2.14.1 from the existing frozen environment. These durations describe these local checks, not embedding inference performance.

Checks cover E30 plus scoped deadline/admission, accounting and redacted-failure behavior: configuration bypass/revalidation, exact bounds, unpaired Unicode, bad counters, request snapshots, reordered vectors, duplicate/missing indexes, wrong profiles/dimensions, non-finite/huge numbers, norm failure, malformed/deep/oversized JSON, missing/zero/invalid usage, live policy denial, Decimal cost boundaries, sanitized failure context, concurrent rejection, cancellation/timeout cleanup and same-instance reuse. OpenAI-shaped responses in tests are mocked; no private source or real provider output is a fixture.

Integration found two typing errors and an unchecked-config serializer warning after the initial 105-case pass. Explicit usage narrowing fixed typing, and suppressing serialization warnings before mandatory configuration revalidation prevents raw invalid values appearing in warnings. A further review found caller-controlled Decimal precision could affect arithmetic; an isolated context and regressions now check that precision two cannot allow a USD 0.001522756 estimated operation through a USD 0.00151 allowance or alter its reported estimate. Final verification supersedes the initial run.

A separate guarded fresh-process import of core and `cragkit.embeddings` passed with socket/subprocess execution rejected. OpenAI, tiktoken, ONNX Runtime, torch and transformers are absent. Psycopg is installed from existing project work but was not loaded. The initial guard also asserted psycopg was absent and failed on that environmental assumption; the corrected check verified the actual no-import boundary without modifying the environment. This was a source-environment check, not clean installed-package acceptance.
