# V2-03 and V2-C1: Native embedding parity

Date: 22 October 2026. State: COMPLETE for the native TypeScript embedding boundary and checkpoint through V2-03. V2 as a whole remains in progress. All providers, input and vectors in these checks are synthetic or mocked; no real inference, billing or retrieval-quality evidence is claimed.

## Implemented behavior

Example: a response returns indexes 1 and 0 for two inputs. Both runtimes return the same input-ordered vectors, profile, usage and error semantics. Missing usage remains null, while a malformed vector is an operational failure rather than absent evidence.

Added `packages/typescript/src/embeddings.ts` and tests under [E-r1](../../../contracts/EMBEDDINGS_V2.md). The optional `cragkit/embeddings` entry point exports the adapter, supported profiles, strict Zod schemas and types. It uses native Node promises and abort signals with caller-owned transport/counter callbacks. No Python server, provider SDK, tokenizer asset or HTTP client is required or created by import. Live enablement stays explicit and default allowance remains zero.

Response validation preserves duplicate-key detection and the distinction between integer and floating-point JSON token spelling. Node uses standard JSON syntax validation plus a bounded scan; this prevents accepting `index: 0.0` when Python rejects it. Equivalent escaped duplicate keys are rejected. Both runtimes now bound decoded JSON depth at 32 and numeric token spelling at 128 characters, including ignored metadata; pathological data does not depend on interpreter-specific recursion or integer limits. The shared fixtures exercise both boundaries.

Exact decimal coefficients/scales with BigInt enforce Node's estimated per-operation admission gate. Configured prices and token counts remain trusted application inputs; this does not establish an actual billing ceiling, account-wide quota or provider price guarantee. Vector normalization, finite values, index coverage and profile identity follow E-r1. No malformed vector is silently normalized.

One operation may be in flight per adapter, with no queue/retry. Caller abort and request deadline propagate a task-owned signal, await cooperative transport settlement and clear timers/listeners before reuse. The application must still supply nonblocking cooperative callbacks and enforce TLS/endpoint/stream bounds in its live transport; arbitrary caller code cannot be sandboxed. Cancellation cannot undo an already-dispatched charge.

Final review found that spreading a caller array could invoke an overridden iterator and bypass the intended bounded snapshot. Node now captures one bounded length and copies by fixed indexes. A regression makes the iterator throw if called and verifies it is never invoked. A second regression checks the counter name is read once within sanitized construction. Neither correction changes the profile or allows broader disclosure.
