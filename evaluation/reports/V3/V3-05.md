## Method choice and learning

Example: a question asks for attempts and delay. Emitting only the attempts anchor yields a missing delay facet and partial status. Try dropping each required anchor from q24 separately and inspect the actual references.

Reviewed-span lookup was selected because the project has human-approved source-span annotations and can validate the behavior without guessing semantic support from a score. This is an initial curated policy, not a learned judge. Development evaluation with these same anchors is in-sample and cannot establish unseen-query accuracy. The caller must select current/applicable policies; compatible anchors are alternatives, while jointly necessary premises need separate facets. Reviewers must include qualifiers. Unannotated contradictions, false source statements and incorrect labels remain possible. Learning practice is pending.
