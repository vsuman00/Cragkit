# V3-01: Reranker contract and shortlist

Date: 2026-10-24. State: COMPLETE for the documented contract/shortlist task. Contract: [RK-r1](../../../contracts/RERANKER_V3.md). Decision: [ADR 0002](../../../docs/decisions/0002-reranker-policy.md). V3 runtime adapters remain unimplemented.

## Outcome

Defined an optional injected reranker boundary with a 40-candidate cap, explicit UTF-8 input/response bounds, model/configuration identity, raw score direction and complete candidate mappings. Default input overflow fails; explicitly selected inference-prefix truncation is observable and never changes canonical source text. Source access/digest verification precedes inference disclosure; final source release requires reauthorization. Shared deadlines, cancellation, call accounting and restricted visible fallback remain requirements for V3-02 implementation.

The shortlist includes local MiniLM and hosted Cohere options, with primary sources, distinct token limits and optional runtime/disclosure/resource gates. Neither real model is selected or configured. The first implementation target is a fake/recorded injectable adapter. No runtime dependency, migration, public wire schema or core import changed.

For example, the synthetic recorded scores `1.25`, `1.25`, `-2.5` rank room-a, room-b, room-c with stable input-order ties. A score is an ordering signal, not proof that the passage answers all facets. A provider returning fewer scores than supplied candidates is rejected rather than filling missing scores.

## Recorded compatibility inspection

The [fixture](../../../contracts/fixtures/reranking.json) contains original, hand-authored synthetic text and responses. A separate model-card reference records only the published score pair and source URL; those numbers are not attached to the synthetic sample or represented as a local inference run. No approved evaluation labels or held-out inputs were opened for this task.

Actual commands, executed serially from the repository root:

```sh
python3 artifacts/V3/V3-01/probe.py > artifacts/V3/V3-01/python.json
node artifacts/V3/V3-01/probe.mjs > artifacts/V3/V3-01/node.json
```

Root then compared the parsed JSON outputs for equality. These task-local inspectors are retained in ignored artifacts, not shipped library adapters or a new product test suite. Results:

- Eleven recorded mapping/order cases produced matching Python/Node outputs: both directions, stable ties despite response order, empty input, missing/duplicate/invented IDs, boolean/string scores and string encodings of nonfinite values.
- Each inspector separately rejected native NaN and positive/negative infinity.
- Both inspected the UTF-8 example: a two-byte prefix ceiling on four-byte `AéB` preserves only `A` as the inference view and leaves the original text unchanged.
- The published MiniLM score pair `8.607138`, `-4.320078` fits the finite higher-first contract. This is recorded documentation compatibility, not a reproduced model result.

These checks validate coherent recorded examples and independently computed ordering. They do not establish executable adapter parity, source authorization, cancellation, worker responsiveness, tokenization, fallback or cap enforcement. Those runtime acceptance cases remain in V3-02. No application regression suite was run for this design-only change. Documentation link/anchor, prose hygiene and whitespace checks are recorded in the tracker handoff.
