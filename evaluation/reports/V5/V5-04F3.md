## Actual native evidence

Root ran Python and Node serially against disposable PostgreSQL 17.11 and pinned Qdrant 1.20.0, using the existing synthetic two-member source and fake-profile vectors. Both runtimes exercised the actual public publication manager, supervisor/recovery initialization, candidate HTTP adapter and authoritative source store. No paid API, local model or hosted database was used.

Eight ordered checks passed per runtime:

1. Stage leaves the active pointer empty and returns no search candidates.
2. Prepared G1 has two physical candidates, but neither can release source text.
3. Published G1 releases two exact canonical UTF-8 excerpts with verified identities, spans and digests.
4. Prepared G2 has four physical candidates; only G1 remains admissible to fresh source requests.
5. Published G2 admits its two members and rejects G1 for fresh admission.
6. A G1 binding retained in its own request releases identical evidence for provider and final purposes, with `stale: true`.
7. Foreign-tenant search returns no candidates; a foreign source request using an actual G2 nomination raises `UnauthorizedScope`.
8. Observed authorizers and HTTP awaits hold no writer SQL lease. Closing the manager preserves borrowed writer/supervisor usability; application teardown closes owned resources and verifies listener absence.

The prepared checks pause an actual publication at its trusted authorizer after durable preparation, inspect QQ/QS while publication is waiting, then resume it. Task cancellation is used only for failed-run cleanup. This is not a process-crash test.
