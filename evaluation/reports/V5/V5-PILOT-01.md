## Boundaries and handoff

This pilot exercises PostgreSQL lexical retrieval, not live embeddings,
reranking, correction, Qdrant or MCP. Evidence budgets are estimated; the
manually copied prompt wrapper and model output have separate token costs.
LLM calls, generated-answer quality, provider rate limits, production identity,
hosted operation, CI and V6 acceptance remain untested here. Session lifetime
is one hour; the disposable database is removed on exit. Caller documents can
be loaded from a private JSON path without adding them to Git.

Final observed headroom: 30 GiB disk, 38 percent system memory free on the
16 GiB machine. Test/service runs were serial; each final run verified process,
listener and private fixture cleanup. No persistent task-owned service remains.

Learning practice is pending. Next: the user runs the checklist and records
confusing steps/failures privately, then repeats with a small real corpus.
V6-01 remains the next formal release task; this pilot does not skip its gates.
