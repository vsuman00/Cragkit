# G2c public security convergence

Both native publication managers now expose `converge_security`. Authority
admission remains an independent short operation. Convergence repairs the
current complete replica set, settles eligible retired journals, reopens the
backend and records completion after a genuine ordinary readback.

For example, a lost acknowledgment can leave a completed HTTP write uncertain.
An explicit convergence retry rotates the actual credential before reconciling
that journal. It does not infer safety from an empty or current-looking read.

The public method follows [QSC-r1](../../../contracts/QDRANT_SECURITY_CONVERGENCE_V5.md).
It requires profile 5 and the matching native recovery/supervisor graph, binds
trusted scope outside the reference, shares one readback budget and deadline,
and charges one logical attempt with zero provider calls. Exact historical
retries return their stored flags. Completion belongs to that intent and does
not claim that a later authorization has converged.

second generation, a completed retry with no new HTTP or metadata mutation,

explicit retry changed the credential generation and completed the pending
work. A later authority change and tombstone during the application callback
refused stale completion while preserving the committed current state.

After revocation, a retained source binding and a fresh revoked scope returned
unavailable before replica convergence. The new allowed scope still resolved
the same immutable published source. Tombstoning denied source release while
physical purge remained pending.
