# V5-04G2a2: Independent public security admission

Status: COMPLETE for authority-only public admission. Physical security convergence, scoped purge, the full fault matrix and V5 exit remain incomplete.

For example, an authorization update must commit while physical publication waits for an uncertain vector operation. `QdrantSecurityManager(writer, authorize_write)` gives that transition its own operation slot and cancellation state. It needs no supervisor or vector transport. Applications supply a separate writer object; writers may share a bounded pool, and ordinary SQL contention/deadlines still apply.

Both native runtimes export the class from the existing optional publication entry point. Explicit initialization initializes only its borrowed writer. `update_authorization` and `tombstone` validate and snapshot the canonical record and trusted scope before calling application code, enforce action/tenant binding, require an actual boolean authorization result and use an internally generated owner token. Each operation charges one logical attempt, preserves the minimum caller/ledger deadline and returns the existing closed nine-field outcome. Exact historical retries reauthorize and preserve durable flags without claiming current replica convergence.

Cancellation is latched before later mutation, including a callback that returns late approval. Admission has no queue. Closing the manager cancels/drains its own work and leaves the borrowed writer/pool open; unfinished work retains admission ownership through actual unwind. Callback failures are redacted consistently across runtimes, and Node error inspection handles hostile proxy/prototype/name hooks. The existing publication manager's behavior is unchanged.
