# V5-04A: Publication and repair contract

Status: complete for design acceptance. V5-04 implementation, native recovery and full V5 remain incomplete. The [version plan](../../../tasks/versions/V5-integrations.md#v5-04-publication-and-repair) defines the required implementation children.

For example, a writer can commit its dispatch record and pause before HTTP. Its lease may expire while it can still resume the request. A successor must preserve uncertainty and fence that credential before reconciling the same intent.

## Accepted artifacts and decisions

[QW-r1](../../../contracts/QDRANT_PUBLICATION_V5.md) freezes the native manager boundary, binary vector seals, ordered generation/intent manifests, additive authority requirements, physical claims, dispatch journal, atomic publication CAS and bounded recovery. [ADR 0004](../../../docs/decisions/0004-qdrant-managed-writes.md) selects the restricted caller-owned supervisor profile. The [fixture](../../../contracts/fixtures/qdrant_publication.json) contains 43 fault cases and 14 numeric cases. The [native matrix](../../../docs/qdrant-publication-acceptance.md) maps every fault case and all 21 QD-r1 failure boundaries.

The exclusive application-owned supervisor survives writer/coordinator failures and owns instance-wide admission, Qdrant lifecycle and immutable credential generations. Recovery gates every document sharing the instance. Supervisor loss remains blocked pending independently verified controlled recovery; automatic takeover is unsupported. The npm implementation must execute natively without requiring a Python service.

Pinned Qdrant 1.20.0 can replay a WAL tail asynchronously when `prevent_unoptimized` is true. The reference profile requires explicit false, complete loading and exact reconciliation; health alone cannot establish completion. This follows the [pinned loading/replay implementation](https://github.com/qdrant/qdrant/blob/v1.20.0/lib/collection/src/shards/local_shard/mod.rs), and remains a required native implementation gate.

Vector seals identify exact submitted Float32LE content, names and full profiles. Dense readback uses the fixed normalized equivalence rule; sparse readback requires exact canonical values. Cosine preprocessing can change dense bits and uses different CPU reduction paths. The [pinned normalization helper](https://github.com/qdrant/qdrant/blob/v1.20.0/lib/segment/src/spaces/tools.rs) uses a squared-length skip threshold of 0.000001. The contract does not equate this with E-r1's input norm tolerance. Differences inside the declared readback tolerance are intentionally accepted; no cryptographic equality of dense stored values or cross-platform runtime measurement is claimed. The publication codec explicitly rejects nonzero values rounding to zero without changing the embedding adapter's contract.
