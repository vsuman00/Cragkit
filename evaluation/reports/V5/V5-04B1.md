## Implementation

The internal Python `_qdrant_vectors.py` and native TypeScript `qdrant-vectors.ts` implement exact full-profile, named-vector seals using framed Float32LE data and UInt32LE sparse indices. They snapshot bounded native inputs, reject hooks/proxies/custom containers, validate original E-r1 values, round ties to even, preserve representable subnormals and canonicalize signed zero. Nonfinite conversion and nonzero underflow fail explicitly. Integral native sparse indices have the same meaning across runtimes; the existing candidate parser is unchanged.

Results hold immutable canonical components, full profiles, seal bytes and hashes. Readback accepts only codec-issued expected objects; a copied or deserialized shape cannot forge that provenance. Dense comparison applies all three fixed component/norm/L2 bounds around ordered binary64 normalization. Sparse values and indices must match exactly after canonical conversion. Known malformed readback becomes `IntegrityViolation`; operational errors remain distinct.

There is no public package export, network/model/database operation, optional driver import, ledger change or publication capability in this slice. Real-profile codec tests validate descriptor binding only; they neither authorize inference nor store synthetic vectors under a real model identity.
