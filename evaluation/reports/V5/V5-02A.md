## Decisions

Use Qdrant `1.20.0` in a task-owned single-node macOS arm64 process for reference integration. The official compressed asset is 29070255 bytes, SHA-256 `531904e822050790bb8c1da6705f801ee48b91eb4c229d0d605ff06f6331b20a`. Its extracted binary reported `qdrant 1.20.0`; binary SHA-256 is `830bd61d0efdba90e0737e174cefe32d4f9e0161b0e2b8684d655fb774544fd3`. This is the tested platform, not a portability claim. [Official release](https://github.com/qdrant/qdrant/releases/tag/v1.20.0).

Select optional HTTPX `0.28.1` on Python `3.14.6` and Node `26.5.0` built-in `fetch` for streaming REST transport. Explicit construction must remain free of network I/O. Request deadlines cover headers, bounded body reads and parsing; redirection, ambient credentials/proxies and automatic retries are disabled. Remote endpoints require verified TLS; the synthetic development process uses explicit loopback HTTP. [HTTPX async API](https://www.python-httpx.org/async/), [Node 26.5 globals](https://nodejs.org/download/release/v26.5.0/docs/api/globals.html#fetch).

The official Python and Node Qdrant `1.20.0` SDK archives were downloaded, integrity-checked and inspected without installing them. The inspected Python REST path calls HTTPX send before parsing buffered content. The Node wrapper defaults to a constructor compatibility request and its timeout middleware supplies its own signal. These default paths do not establish QC-r1's combined streaming byte bound, cancellation and construction requirements. A later SDK binding needs its own bounded integration evidence. Direct REST avoids installing NumPy and gRPC for these operations. [Python distribution metadata](https://pypi.org/pypi/qdrant-client/1.20.0/json), [Node distribution metadata](https://registry.npmjs.org/@qdrant%2fjs-client-rest/1.20.0).

QC-r1 declares synthetic dense and sparse profiles accurately, restricted string equality/membership filters, nested AND/OR, complete trusted preselection predicates, an operation ceiling of 64 candidate slots and explicit failures for unsupported capabilities. The wire request's maximum candidate setting remains 10000. Returned nominations contain identities and score metadata; they contain no source text and confer no authority. V5-03 must verify current permissions and immutable sources before provider disclosure and final release.

```sh
uv pip freeze --python artifacts/V5/V5-02A/httpx-env/bin/python
```

The final one-shot probe passed eight server-readiness groups: exact version; unauthenticated collection access denied; one loopback listener with gRPC/cluster listeners absent; completed dense+sparse point writes; dense scoped preselection; sparse scoped preselection; required-filter miss; exact owned collection deletion and empty inventory. Only four synthetic points were inserted. The server used one search worker, one API worker, telemetry disabled, CORS disabled, snapshot URL recovery disabled, a generated private API key and an isolated temporary data directory. It was terminated after verification; the private config/key and data directory were removed.

Serial transport prototypes passed five Python checks: dense query, sparse query, a local oversized-stream rejection with response closure, an outer deadline closing a local stalled stream, and owned-client closure. Four Node checks passed: dense query, sparse query, a local oversized-stream rejection with reader cancellation, and propagation of an already-aborted signal. These are transport mechanism probes. Mid-flight Node disconnect, hostile server responses, constructor guards, shared-ledger integration and the complete adapter cases still require implementation tests.

The isolated Python environment installed HTTPX `0.28.1`, anyio `4.15.1`, certifi `2026.10.23`, h11 `0.16.0`, httpcore `1.0.9`, idna `3.20` and typing-extensions `4.16.0`. This temporary probe installation did not change project manifests or locks. The environment is removed after the probe; subsequent adapter installs require their own frozen project dependency evidence.

Python standard-library UUIDv5 and an independent Node crypto/SHA-1 implementation agreed on all four identity tuples, including quotes, backslash/newline and composed/decomposed Unicode. Canonically equivalent Unicode remains distinct because immutable identities are not normalized. These calculations establish the specification formula, not an adapter implementation or collision-freedom proof. QD-r1 still requires an atomic ownership registry before writes.

Both Sol peers contributed separate contract/fixture files and coordinated directly. The contract peer assembled them and transferred ownership before root integration. Independent Sol review found no material contradiction; root additionally inspected transport sources and corrected the selected dependency profile, candidate ceiling and numeric bounds. Root owns final fixture, link, prose and scope checks and their recorded results in the tracker.

## Limits and next work

Observed headroom before acquisition was 39 GiB free disk and 55 percent free system memory. The final server RSS snapshot was 38464 KiB; it is not peak RSS or a workload benchmark. The macOS binary emitted a jemalloc background-thread warning; version/readiness probes still succeeded. Docker's daemon was unavailable and was not started. No model, paid provider, remote development database, production service, package publication or hosted CI was used.

For example, an old grant can still nominate a point, but it cannot authorize source text. Failure case: a malformed or unsupported required filter must fail before dispatch, rather than disappear from a query. Next implement V5-02B/C against QC-r1, then run V5-02D against the isolated server. V5-03/04 retain source authority, revocation races, physical point reservations, publication and repair acceptance. Learning practice remains unassessed.
