## Implementation

Both internal native `PostgresQdrantRecovery` modules borrow a dedicated supervisor pool, actual controller and bound verifier. Explicit initialization checks history/catalog compatibility and registers or validates actual instance identity. Each SQL lease checks the fixed NOLOGIN capability, safe memberships/flags, ownership restrictions, active RLS and exact effective table/column/helper grants. The supervisor reads operational metadata and cannot select source bytes, original vectors, intent bytes or journal request bodies.

Recovery commits the SQL block before actual process/key fencing, reuses the same blocked identity/epoch, and advances an exact existing document owner without changing its token or intent. Settlement uses a privately issued E2a receipt and a fresh writer projection, outside the supervisor lease, then locks and preflights the whole target intent. Current-generation, unsupported or uncovered work cannot be silently skipped. Settled retries return zero. The instance remains blocked until every journal is settled, including other documents whose scopes the caller has not supplied.

Reopening first seals recovery issuance and closes handles, then commits the global SQL open state under a backend lock. A single-use private capability bound to that exact controller and sealed barrier enables native ordinary admission. Lost commit acknowledgment keeps admission sealed until the same durable identity is read back; no blind update retry occurs. The coordinator closes only its own operation and leaves borrowed pools/controller lifetime to the application.

## Concurrent-coordinator finding

Serial acceptance initially passed, but review found a gap between one coordinator's SQL block and physical fencing and another coordinator's SQL/native reopening. Per-object active flags did not serialize separate coordinators sharing the actual supervisor. Root's added native regression failed at the competing-reopen refusal before the fix.

The final E2b-r2 implementation holds a supervisor-owned exclusive session across each complete coordinator operation. Its private facade carries a token for native lifecycle/gate calls. Competing/nested coordinator entry, raw mutations in the owner callback or inherited sibling context, preexisting native lifecycle work and expired facades are rejected. Started asynchronous facade work drains before token expiry; native cancellation waits for actual unwind before releasing ownership. The session supplies sequencing permission, not quiescence or SQL proof. The latter still require actual fencing, scoped readback and committed private settlement.

Sol peers and the independent reviewer agreed on this correction directly; no unresolved material issue required Astra. Root owned the controller/helper changes and actual acceptance. Both runtime peers delivered separate recovery modules/tests, with Python assembling. The third Sol peer wrote the Node native consumer and reviewed the independent control/guard sources. All paths transferred before final root verification.
