No new runtime dependency is required.

Ten adapter cases passed. The affected corrective, PostgreSQL-backend and Qdrant candidate/source suite passed 124 Node tests with strict build. Python's corresponding affected suite passed 211 tests and strict mypy over 50 files. New tests cover exact emitted spans, profile mismatch, unsupported modes, provider-budget refusal, source revocation/outage, source-byte allowance, cancellation and unknown usage after provider dispatch. V5-07C will run those combinations with disposable servers and the same deterministic data/providers.
