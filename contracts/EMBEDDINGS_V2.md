# Embedding adapter contract E-r1

V2-02/V2-03 boundary contract. Implements the [accepted profile decision](../docs/decisions/0001-embedding-profile.md); this is not live-provider or retrieval-quality evidence.

## API and ownership

Python optional entry point: `cragkit.embeddings`. Root imports stay unchanged. No SDK, tokenizer, model assets, network transport or credentials are discovered or installed. The application injects a caller-owned cooperative async transport and a fast deterministic token counter; the adapter never closes them. Node parity follows in V2-03. OpenAI documents `cl100k_base` for this model in its [embedding guide](https://developers.openai.com/api/docs/guides/embeddings); this slice does not install that tokenizer.

Public models use strict, frozen Pydantic models with forbidden extra fields. Revalidate model instances at adapter construction; do not trust `model_construct`/unchecked copies. Immutable results copy vectors into tuples. All input/request/result state is per operation.

- `EmbeddingProfile`: fields `profile_id`, `provider`, `model`, `dimensions`, `tokenizer`, `normalization`. Only these exact profiles are supported. Export `OPENAI_PROFILE` and `FAKE_PROFILE`:
  - `openai_te3small_1536_r1`, `openai`, `text-embedding-3-small`, 1536, `cl100k_base`, `l2`.
  - `fake_embedding_1536_v1`, `fake`, `fake_embedding_model_v1`, 1536, `fake-byte-v1`, `l2`.
- `EmbeddingLimits`: defaults/hard maxima `max_items=8` (8), `max_input_bytes=8192` (8192), `max_batch_bytes=32768` (32768), `max_input_tokens=2048` (8192), `max_batch_tokens=8192` (32768), `max_response_bytes=1048576` (2097152). Positive integer values only; applications may reduce them. No automatic splitting, truncation or retries.
- `EmbeddingPolicy`: `allow_live=False`, `max_cost_usd=0.0`, `usd_per_million_tokens=None`. Costs must be finite, nonnegative and no greater than 1000000; a configured price must be positive. Per-operation cost reservation is derived from the trusted token counter and configured price. This is an estimated preflight gate, not a verified provider-billing ceiling, global quota or immutable provider price. Caller Decimal settings cannot weaken this calculation.
- `TokenCounter` protocol: `name: str`, `count(text: str) -> int`. Name must match profile tokenizer. Counts must be positive safe integers (at most 2147483647), excluding booleans. The application must supply an accurate tokenizer for live input. Fake counting is a declared synthetic protocol, not a real-model token estimate.
- `EmbeddingTransport` protocol: async `__call__(body: bytes, *, deadline: float, max_response_bytes: int) -> bytes`. The adapter supplies compact JSON UTF-8 body. A live implementation binds direct OpenAI HTTPS endpoint outside query input, refuses redirects, applies connect/read/deadline and streaming response bounds, disables internal retries and propagates cancellation. The injected implementation remains trusted application code; this boundary cannot sandbox it or stop a blocking/noncooperative implementation. No concrete HTTP transport is bundled in this slice.
- `EmbeddingAdapter(transport, token_counter, *, profile=FAKE_PROFILE, limits=None, policy=None)`; `embed_batch(texts, *, deadline)` and `embed_query(text, *, deadline)` return `EmbeddingBatch`. Query delegates to a one-item batch. Inputs are list/tuple of strings, snapshotted before any await; reject generators and scalar strings. Deadline is an explicit finite monotonic float/int, excluding bool.
- `EmbeddingBatch`: `profile: EmbeddingProfile`, `vectors: tuple[tuple[float,...],...]`, `usage: EmbeddingUsage`, `provider_calls: Literal[1]`, `synthetic: bool`.
- `EmbeddingUsage`: nullable `prompt_tokens`, `total_tokens`, `cost_usd`, and `cost_kind: Literal['known','estimated','unknown']`. Missing token usage stays null. Fake cost is known zero because the transport is declared synthetic; live cost is estimated from actual reported tokens and configured price, otherwise unknown/null. Never replace missing live usage with zero. Failed/cancelled dispatched operations can still incur provider charges; exceptions do not establish zero usage or zero billing.

## Validation, admission and failure

Reject empty batch/text, invalid Unicode (including unpaired surrogates), item/UTF-8 byte/token limit excess and invalid counter outputs before transport dispatch. Empty means zero characters; whitespace is preserved. Check character count against byte cap before encoding so huge rejected input is not copied. Bound summed UTF-8 bytes and tokens. Do not log input or use it as instructions.

Direct model construction uses Pydantic `ValidationError`. The adapter revalidates trusted configuration and converts invalid/unchecked configuration, input or counter output to sanitized `InvalidRequest`. A counter name mismatch, disabled live policy, absent live price or insufficient per-operation cost allowance gives `UnsupportedCapability`. Fake mode works with default zero live allowance; setting `allow_live` does not change profile identity. Caller configuration and token counting are trusted and are not a security boundary against malicious application code.

Permit one in-flight operation per adapter, zero queued operations. A concurrent call fails `ProviderUnavailable` before dispatch. No semaphore with unlimited waiters. Admission resets in finally on success/failure/deadline/cancellation. One transport call per accepted operation, no retry. Enforce the shared deadline around the await and recheck after counting and response validation. Caller cancellation propagates and the cooperative transport is cancelled/awaited before reuse. Expired/transport timeout gives `DeadlineExceeded`. Other transport faults give sanitized `ProviderUnavailable`; exception context/trace must not contain transport error text, raw response or inputs.

Request JSON has exactly `model`, `dimensions`, `encoding_format: 'float'`, `input` (snapshot array). Response must be bytes within the configured cap; reject invalid UTF-8/JSON, duplicate object keys and nonstandard NaN/Infinity. Ignore unneeded provider fields after bounding the raw response. Require matching `model`, a `data` array with exactly one element per input and unique integer indexes covering `0..n-1`; reorder vectors by index. Each embedding is an array with exactly 1536 numeric finite components; booleans and strings are not numbers. Reject zero norm and require `abs(sqrt(sum(x*x))-1) <= 0.001`. Never normalize, truncate or silently coerce invalid vectors.

Wrong returned model or vector dimension gives `EmbeddingProfileMismatch`; other malformed responses give sanitized `ProviderUnavailable`. A present `usage` object requires integer `prompt_tokens` and `total_tokens`, both in `0..2147483647`, with `total_tokens >= prompt_tokens`. Missing/null usage is unknown. Live usage above trusted counted tokens is a provider/accounting failure (`ProviderUnavailable`), not a zero-cost result; a sent request cannot be undone. Preserve actual returned usage on success. Cost reservation/estimation uses decimal arithmetic at the comparison boundary to avoid allowing an over-budget request through floating-point rounding. Error classes retain existing wire codes/messages.

## Verification and learning

Use synthetic vectors with a distinct fake model/profile. Test reordered vectors; missing usage; invalid numeric values, dimensions and indexes; malformed/oversized JSON; token/byte/item limits; live-policy denial without actual network calls; transport faults; queued rejection; deadline/cancellation and subsequent same-instance reuse. Use existing test tools serially. Fake responses and a mocked OpenAI-shaped response do not establish model quality, endpoint availability, TLS behavior or billing. A configured live smoke remains separate.

Failure example: accepting a duplicate index can attach the wrong vector to an authorized source even though every vector has the right length. Length validation and index coverage are separate checks. Optional exercise: explain why two input texts require two distinct returned indexes, then predict what happens when index 1 is missing.
